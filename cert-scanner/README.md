# Сканер сертификатов сайтов российских банков

Снимает TLS-сертификаты с сайтов банков, определяет удостоверяющий центр, сохраняет снимок на дату и генерирует отчёт о переходах между УЦ — в формате поста.

## Файлы

| Файл | Что это |
|---|---|
| `bankcerts.py` | сканер и генератор отчёта (только стандартная библиотека Python 3.8+) |
| `bot.py` | Telegram-бот: запуск проверки и получение отчёта по запросу |
| `banks.json` | список целей: 25 крупнейших банков (`rank`) + ещё ~40 банков + инфраструктура (НСПК, ВЭБ.РФ, ЦБ, СБП, Госуслуги) |
| `config.example.json` | шаблон настроек бота (свой `config.json` в репозиторий не попадает) |
| `snapshots/` | снимки по датам, `YYYY-MM-DD.json` |
| `reports/` | сгенерированные отчёты |
| `examples/` | демо-снимки и отчёт, воспроизводящие пост от 31.07 → 05.08 |

## Использование

```bash
python3 bankcerts.py scan                    # топ-25 банков (по умолчанию)
python3 bankcerts.py scan --scope banks      # все банки из списка
python3 bankcerts.py scan --scope all        # банки + инфраструктура
python3 bankcerts.py scan --workers 24 --timeout 10

python3 bankcerts.py report                  # сравнить два последних снимка
python3 bankcerts.py report snapshots/2026-07-31.json snapshots/2026-08-05.json

python3 bankcerts.py show                    # показать последний снимок
python3 bankcerts.py list --scope all        # список целей
```

Отчёт печатается в консоль и сохраняется как `report_<дата1>_<дата2>.md`: сверху готовый текст поста, ниже — техническая сводка (таблица по УЦ, истекающие сертификаты, кто не проходит проверку системным хранилищем доверия).

Запускать нужно **на своём компьютере** — из песочницы Cowork нет выхода в интернет к банковским доменам.

## Telegram-бот

Обновление данных по запросу прямо из чата: `/scan` запускает проверку, `/report` присылает готовый текст поста.

**Настройка (один раз):**

1. В Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя и username → он вернёт токен вида `12345678:AA...`
2. Скопируйте шаблон и вставьте токен:
   ```bash
   cd ~/Job/PSB/psb/cert-scanner
   cp config.example.json config.json
   open -e config.json
   ```
3. Запустите бота и напишите ему `/start` — он ответит вашим `user_id`:
   ```bash
   python3 bot.py
   ```
4. Впишите этот id в `allowed_user_ids` (например `[123456789]`), перезапустите. Пока список пуст, бот никого не пускает к сканеру — это защита от чужих.

`config.json` в `.gitignore`, токен в репозиторий не уедет.

**Команды:**

| Команда | Что делает |
|---|---|
| `/scan` | проверить сейчас, топ-25 |
| `/scan all` | все банки + инфраструктура (60+ сайтов, 1–2 мин) |
| `/report` | сравнить два последних снимка, прислать отчёт + файл `.md` |
| `/report 2026-07-31 2026-08-12` | сравнить конкретные даты |
| `/post` | только текст поста, без техсводки — можно сразу переслать в канал |
| `/last` | сводка по последнему снимку |
| `/snapshots` | список снимков |
| `/targets all` | что сканируем |

После `/scan` бот показывает прогресс (`Готово: 34/68`), а если предыдущий снимок есть — сразу присылает отчёт о переходах.

**Работа в фоне.** Бот живёт, пока открыт терминал. Чтобы не держать окно:

```bash
cd ~/Job/PSB/psb/cert-scanner
nohup python3 bot.py > bot.log 2>&1 &
```

Остановить: `pkill -f bot.py`.

Ежедневный автоскан — впишите в `config.json` время и свой chat_id:
`"daily_scan_at": "09:00", "daily_scan_chat_id": 123456789`.

## Как определяется УЦ

Берётся `issuer` (O + CN) листового сертификата и матчится по правилам в `CA_RULES` (`bankcerts.py`). НУЦ Минцифры опознаётся по `Russian Trusted *` / `The Ministry of Digital Development and Communications`. Незнакомый issuer попадает в отчёт как есть — правило можно дописать одной строкой.

Дополнительно каждый сайт проверяется вторым, уже доверительным, хендшейком: поле `trusted_by_system_store: false` означает, что цепочка не валидируется системным хранилищем — практический признак сертификата НУЦ на обычной ОС.

## Что собирается по каждому сайту

`ca`, `issuer_o`, `issuer_cn`, `subject_cn`, `not_before`, `not_after`, `days_left`, `serial`, `sig_alg`, `key`, `san_count`, `sans`, `fingerprint_sha256`, `tls`, `cipher`, `trusted_by_system_store`.

Отпечаток и серийник позволяют ловить перевыпуск сертификата у того же УЦ — не только смену УЦ.

## Если что-то не работает

**`CERTIFICATE_VERIFY_FAILED: self-signed certificate in certificate chain` при старте бота.** На машине работает VPN/прокси с подменой TLS (Shadowrocket, FoXray и подобные). Python не читает связку ключей macOS и не знает корневой сертификат прокси. Скрипт собирает бандл корней из Keychain сам (`.ca_bundle.pem`, обновляется раз в сутки) — если ошибка осталась, значит корень прокси не установлен в системную связку: либо добавьте его туда, либо выключите прокси.

**Таймауты на российских банках (Сбербанк, ВТБ, Почта Банк…).** Тот же прокси: сайты банков не отвечают на подключения с зарубежных адресов. Для честной картины сканируйте с российского IP, без VPN.

**`UNSAFE_LEGACY_RENEGOTIATION_DISABLED`.** Сервер не поддерживает RFC 5746 — обрабатывается, отдельных действий не требуется.

## Сохранение результатов в git

Команда `/git` в боте коммитит и пушит `snapshots/` и `reports/`. После `/scan` это происходит автоматически (`"git_autosave": true` в `config.json`).

Вручную:

```bash
cd ~/Job/PSB/psb && git add cert-scanner/snapshots cert-scanner/reports && git commit -m "снимок $(date +%F)" && git push
```

## Точность и оговорки

- Парсер: если установлен `cryptography` (`pip install cryptography`) — используется он; иначе системный `openssl`. Оба протестированы и дают идентичный результат.
- Домены в `banks.json` — основной + запасные (`alt`), пробуются по очереди. Несколько доменов вне топ-25 указаны предположительно (Банк Синара, Свой Банк, Вайлдберриз Банк, Озон Банк) — при ошибке подключения их видно в конце отчёта, поправьте в JSON.
- Сканируется только основной сайт. Интернет-банк и мобильные API часто живут на других доменах с другими сертификатами — при желании добавьте их отдельными целями.
- Банки за CDN могут отдавать разные сертификаты с разных точек; результат отражает то, что видит ваш провайдер.

## Регулярный запуск

macOS/Linux, ежедневно в 09:00:

```bash
0 9 * * * cd /путь/к/папке && /usr/bin/python3 bankcerts.py scan --scope all >> scan.log 2>&1
```

Затем `python3 bankcerts.py report` в любой момент сравнит два последних снимка.
