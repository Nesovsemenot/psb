# psb

Общий репозиторий проектов для банка. Один проект — одна папка верхнего уровня.

## Проекты

| Папка | Что это | Статус |
|---|---|---|
| [`cert-scanner/`](cert-scanner/) | Сканер TLS-сертификатов сайтов российских банков: снимок по датам + отчёт о переходах между УЦ | рабочий |

## Соглашения

- Новый проект = новая папка в корне, внутри обязательно свой `README.md` с описанием и командами запуска.
- Данные, которые накапливаются по датам, лежат в подпапке `snapshots/` или `data/` в формате `YYYY-MM-DD.*`.
- Готовые отчёты и выгрузки — в `reports/` внутри проекта, файлы именуются с датой.
- Крупные бинарные выгрузки (xlsx, zip, скриншоты) в репозиторий не коммитим — см. `.gitignore`.

## Подключение к удалённому репозиторию

```bash
cd ~/Job/PSB/psb
git remote add origin git@github.com:<username>/psb.git
git push -u origin main
```
